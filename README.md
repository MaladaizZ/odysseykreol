## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## mON PERSO / 
Ma vision pour Odyssey : une plateforme qui donne envie de découvrir la Guadeloupe, mais surtout de mieux la connaître. Une plateforme où les habitants peuvent transmettre leurs expériences, raconter leur territoire, partager leur culture et contribuer à une mémoire collective numérique.

Je voudrais que nous construisions quelque chose qui ait une vraie identité, une vraie utilité et une qualité technique professionnelle.

Et surtout, que son architecture nous permette de continuer à ajouter des fonctionnalités dans plusieurs années sans devoir tout recommencer.
